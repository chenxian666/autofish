# AutoFish · 三角洲行动自动钓鱼

> A background fishing assistant for *Delta Force*. It listens to **system audio**, decides whether the bite is *your own fish*, and clicks for you — using not just **sound recognition**, but also **spatial (stereo panning) judgement**.

一个**只靠系统音频**工作的自动钓鱼脚本：监听游戏声音，判断这次咬钩是不是**你自己的鱼**，是就自动完成收鱼、抛竿。**不截屏、不读游戏内存、不注入进程、不装驱动**（设计依据见 [`docs/adr/0001`](docs/adr/0001-audio-only-no-vision.md)）。

---

## 为什么它比"听个响就点"更靠谱

市面上大多数"声音识别"脚本只做一件事：**听到咬钩音就点**。但三角洲行动里，同一个钓点会有好几个玩家，大家上钩播的是**同一段咬钩音**——光听"有没有声音"根本分不出是谁的鱼。

这个脚本在"识别声音"之上，又加了一层**方位判断**：

| 判据 | 它回答 | 靠什么 |
| --- | --- | --- |
| **存在判据**（归一分） | 音频里**有没有**出现咬钩音 | 与模板的归一化互相关相似度 |
| **归属判据 · 电平** | 这条鱼**离你多近** | 整体音量（dBFS），用**区间**卡上下限 |
| **归属判据 · 声像差** | 这条鱼**在不在你正前方** | 左右声道电平差（dB），0 = 正中间 |

你自己的鱼就在跟前、且在视线正中，所以**电平落在某个区间内、声像差接近 0**；别人的鱼在远处（音量衰减）或在侧面（左右声道不平衡）。于是：

- 远处的鱼 → **电平太低**，拦掉
- 贴脸的枪声 / 爆炸 → **电平太高**，拦掉（可设上限）
- 侧面的鱼 → **声像差太大**，拦掉

三层判据全过，才点鼠标。这套思路的完整论证见 [`docs/adr/0002`](docs/adr/0002-ownership-cues-level-and-pan.md)。

## 功能特性

- **纯音频，零侵入**：WASAPI 回环监听系统声音，不碰游戏进程、内存、画面、输入设备。
- **声音识别 + 方位判断**：归一分（像不像）+ 电平（远不远）+ 声像差（偏不偏）三层把关。
- **自动收鱼序列**：确认命中后自动「抬杆 → 打断检视 → 抛竿」，还能设兜底补杆。
- **一键标定**：跑一段只听不点，自动算出适合你本机环境的门限（音量、方位都考虑）。
- **图形界面 + 热键**：F9 开始/停止挂机，F10 退出；挂机时自动收起窗口停靠屏幕右下角。
- **留档可回溯**：每次判定记一行 CSV + 一段录音，事后能听出来哪次是自己、哪次是误判。
- **免 Python 运行**：可选打包成无黑窗口的单文件 exe（见[打包说明](打包成exe.md)）。

## 环境要求

- **Windows**（依赖 WASAPI 回环 + Tk 图形界面）
- 游戏：**三角洲行动**（Delta Force），音频走默认输出设备
- 运行 exe 版：无需任何依赖；运行源码版：Python 3.10+，依赖 `numpy`、`soundcard`

> 三角洲行动自带反作弊（ACE）、以管理员身份运行，因此脚本也必须以管理员身份运行，
> 否则 Windows 的 UIPI 会静默丢弃注入的点击（详见[使用说明](自动钓鱼使用说明.md)）。

## 安装与运行

### 方式一：直接跑 exe（推荐，无需 Python）

```bash
# 双击即可，无黑窗口。首次启动约 2~3 秒（单文件包需先解包）。
AutoFish.exe
```

exe 已内嵌"需要管理员权限"清单，双击会在 UAC 弹窗，点「是」即可。

### 方式二：源码运行

```bash
pip install numpy soundcard
python autofish.py            # 图形界面
python autofish.py --nogui    # 纯控制台
python autofish.py --list     # 列出音频设备
python autofish.py --calibrate 120   # 标定：只听不点，跑 120 秒
```

> 运行期数据（配置 / 模板 / 录音 / 日志）统一存在 `%LOCALAPPDATA%\AutoFish\`，
> exe 与源码两种方式**共用同一份配置和标定结果**，随便换着用。

## 使用示例

**第一次用，按这个顺序：**

1. **标定**：点界面「标定…」，填 120 秒，然后正常钓鱼（这段时间只听不点）。
   结束后脚本会算出建议门限并自动填进输入框，点「应用门限」。
2. **检查三个状态**：「设备」= `扬声器 (FxSound Audio Enhancer)`，「前台」「光标」都显示 OK。
3. **鼠标停在钓鱼 UI 上别动**（点击打在光标当前位置，脚本不移动鼠标）。
4. **按 F9** 开始挂机，窗口会自动收起并停靠到右下角。

**关键门限**（改完点「应用门限」）：

| 门限 | 含义 | 调太紧 | 调太松 |
| --- | --- | --- | --- |
| 归一分 ≥ | 音色像不像（存在判据） | 听漏 | 什么声音都算 |
| 电平 ≥ / ≤ | 离你多近（区间） | 自己的鱼被拦 | 远处/太响的也骗过 |
| 声像差 ≤ | 在不在正前方 | 视角稍偏就点不到 | 侧面的鱼也骗过 |

**零风险自测**（不用开游戏）：直接播放 [`测试音频/`](测试音频/说明.md) 里的模拟素材，
看判定结果即可验证三道闸门是否生效——因为窗口检查不过，它**绝不会真的点鼠标**。

完整的标定流程、故障排查、窗口停靠说明，见 [`自动钓鱼使用说明.md`](自动钓鱼使用说明.md)。
