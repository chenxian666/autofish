# 归属判据建在电平与声像差上，而不是归一分

## Status

accepted

## 背景

归一分（模板与音频缓冲的归一化互相关系数）看起来最适合回答「是不是我的鱼」，实际上不能。

它是归一化的：分子分母同时含信号幅度，幅度会约掉。实测（`probe_test.py`）：

| 输入 | 归一分 |
| --- | --- |
| 同波形降低 20 dB | 1.0000 |
| 同波形左偏 3 / 6 / 12 dB | mono、L、R 三个得分全部 1.0000 |
| 低通到 12% 带宽 | 0.9763 |
| 叠加 30 ms 混响 | 0.6380 |
| 白噪声 | 0.0160 |

也就是说归一分对**音量（距离）免疫**、对**方位免疫**。而这两者恰好是三维音频里唯一能区分声源的线索。游戏对他人咬钩音施加的正是距离衰减与方位声像。

## 决定

把两件事拆开：

- **归一分**只回答「音频里刚才有没有出现咬钩音」——有没有。
- **电平**（命中片段的整体音量，dBFS）与**声像差**（左右声道电平之差，dB）回答「这个咬钩音是不是我的鱼」——是谁的。

## Considered Options

- **要求左右声道各自的归一分都过阈值**：无效。已实测，左偏 12 dB 时左右得分仍是 1.0000，因为归一化把通道间的能量差抹掉了。
- **单纯提高归一分阈值**：只在游戏对远处音源施加了混响/时变处理时才有效（混响能把分数从 1.0 压到约 0.6）。是否可用取决于游戏的距离模型，必须先实测。

## 后果

- 判据是统计性的，不是硬判据：他人若恰好站在你视线正前方，声像差同样接近 0。
- 门限依赖实际听音环境，**必须引入标定**，不能写死默认值。
