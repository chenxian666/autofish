# 只用音频回环，不做任何图像识别

## Status

accepted

## 背景

独立自动钓鱼脚本需要一个「这次咬钩是不是我的鱼」的判据。技术上最可靠的判据是画面确认——直接看游戏界面上的咬钩提示（浮漂下沉、感叹号图标、收杆按钮），因为他人咬钩不会改变你自己的界面。

用户明确排除了这条路线：担心截屏 / 图像识别这类行为被反作弊启发式判定为外挂。

## 决定

系统的全部输入只有**系统音频回环**（WASAPI loopback），全部输出只有**鼠标左键注入**（`mouse_event`）。不截屏、不读游戏进程内存、不注入游戏进程、不加载任何驱动。

## 后果

- 失去了唯一能一锤定音的判据，归属判断只能建在音频特征上，因此**必然是统计性的、带有残留误触发**。
- 换来的是：整个工具运行在自己的进程里，只在系统音频端点和输入队列上留下痕迹。
- 将来若有人想「顺手把画面确认加上」，先读这份 ADR：这是刻意的取舍，不是遗漏。
