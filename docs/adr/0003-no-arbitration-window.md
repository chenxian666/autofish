# 不给点击加观察窗口，每一次命中都独立瞬时判定

## Status

accepted

## 背景

在人多时抑制误触发，最有效的手段是**候选仲裁**：收到命中后先不点，等 300～500 ms 把这段时间里出现的所有候选收集起来，再选电平最高（离自己最近）或声像差最接近 0 的那一个点击。

但游戏从咬钩音响起到必须点击之间的窗口极紧（"特别紧，得点得特别快"）。任何延迟都可能把已经上钩的鱼放跑。

## 决定

不做任何延迟仲裁。每一次命中都在当下独立完成归属判定，判过即点。

## Considered Options

- **延迟仲裁**：否。会直接丢鱼，而丢鱼比误触发代价更高——误触发浪费的是一次抛竿，丢鱼浪费的是已经等到的机会。
- **事后纠错**：否。点击一旦发出无法撤回。

## 后果

- 人多时可能出现连续误触发。这是**已知且被接受**的残留风险（见 ADR-0001，不做画面确认也同样接受残留误触发）。
- 归属判据没有第二次机会，**必须在单次命中上就足够准**。这抬高了声像差与电平这两个判据的门限质量要求，也让「标定」从可选项变成必选项。
- 反过来，这也说明「兜底补杆」必须按"20 秒内一次都没触发"来算（而不是"没有命中"）：既然误触发会消耗掉触发配额，就必须确保真正空竿时兜底一定会介入。
